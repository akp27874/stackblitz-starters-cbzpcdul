filter works!

The filter operator in RxJS is a filtering operator used to selectively allow values to pass through an observable stream based on a condition. It works almost identically to JavaScript's native Array.prototype.filter() method, but instead of working on a static array, it works on individual values arriving over time.

If a value satisfies the condition (returns true), it passes down the pipeline. If it fails the condition (returns false), it is discarded and will not trigger subsequent operators or subscribers.
